# 🌀 Pixstorm Automation Bot

Автоматизированный набор Python-скриптов для работы с торговой площадкой [Pixstorm](https://trade.pixstorm.ru/):  
выполняет авторизацию, отмену активных заявок на покупку/продажу, обработку предметов и выставление новых ордеров.  
Использует **Selenium + Firefox (Geckodriver)** и **многопоточность** для повышения скорости.

---

## 📦 Структура проекта

| Файл | Назначение |
|------|-------------|
| `prod.py` | Основная логика торговли: авторизация, получение цен, покупка и продажа предметов. Работает по списку ссылок `YouPath/produrls.txt`. |
| `cancel_purchases.py` | Скрипт для **отмены всех активных заявок на покупку**. |
| `cancel_sales.py` | Скрипт для **отмены всех активных заявок на продажу**. |
| `cancelb.py` | Параллельно запускает оба скрипта (`cancel_purchases` и `cancel_sales`) в отдельных потоках. |
| `avt2.py` | Облегчённая версия `prod.py` — тест или альтернативный вариант для проверки логина и ссылок. |
| `avtobot.py` | Главный управляющий скрипт, запускает все этапы по циклу: отмена заявок → авторизация → торговля → пауза 40 минут. |
| `YouPath/` | Рабочая директория: кэш Firefox, `geckodriver.exe`, `produrls.txt` (список ссылок), скриншоты ошибок и временные файлы. |

## ⚙️ Установка и запуск

### 1. Установи зависимости

```bash
pip install selenium pyotp
```

> ⚠️ Убедись, что установлен **Firefox** и **Geckodriver**.  
> Путь к `geckodriver.exe` указывается в коде (`YouPath` или полный путь).

### 2. Настрой переменные

В файлах `prod.py`, `avt2.py`, `cancel_purchases.py`, `cancel_sales.py` нужно указать:

```python
EMAIL = "your_email"
PASSWORD = "your_password"
TOTP_SECRET = "your_2FA_secret"
```

> TOTP (2FA)-ключ можно получить из Google Authenticator или Authy (формат Base32).

### 3. Подготовь список ссылок

Файл: `YouPath/produrls.txt`

Пример:
```
https://trade.pixstorm.ru/market/skin1
https://trade.pixstorm.ru/market/skin2
https://trade.pixstorm.ru/market/skin3
```

## 🚀 Запуск

### 🔹 Основной режим
```bash
python prod.py
```
Скрипт авторизуется, получает цены, определяет разницу и автоматически покупает/продаёт предметы.

### 🔹 Очистка ордеров
```bash
python cancelb.py
```
Одновременно отменяет все активные ордера на покупку и продажу.

### 🔹 Полный цикл (автобот)
```bash
python avtobot.py
```
Запускает полный цикл действий каждые **40 минут**:
1. Отмена заявок  
2. Повторная авторизация  
3. Торговля  
4. Ожидание и повтор

## 🧠 Основные возможности

- ✅ Полная автоматизация входа (логин + пароль + 2FA TOTP)  
- 🧩 Работа с элементами через Selenium WebDriver  
- 💰 Расчёт прибыли (`sell_price - buy_price * 1.15`)  
- 🔁 Циклическая торговля с перезапуском каждые 40 минут  
- 💬 Отладочные сообщения и скриншоты при ошибках  
- ⚡ Поддержка многопоточности (в `prod.py` можно увеличить `num_threads`)  
- 🔒 Безопасная авторизация с фоллбэком при ошибках входа  

---

## 🧾 Логи и отладка

- Все ошибки и скриншоты сохраняются в `YouPath/crashes/`
- Каждый запуск создаёт отдельные временные папки `YouPath/thread_X/`
- При неудачной авторизации выполняется повторная попытка (`click_login_and_account` → `login_to_pixstorm`)
